## 0. 怎么用

- 状态只有三种：`未开始` / `部分` / `完成`
- 分「契约 / 后端 / 前端」三栏记录，因为**契约写完不等于能力可用**
- 完成一步就把对应格子改成 `完成`，提交信息里带上步骤编号（如 `1.10`）
- 契约栏指 `docs/*-contract.md`，后端栏指 `apps/server/src`，前端栏指 React 工程
